# Portfolio Profesional - Sebas.Dev

Este es mi portfolio personal desarrollado como una aplicación web moderna, minimalista y de alto rendimiento.

##  Tecnologías Utilizadas
* **HTML5:** Estructura semántica.
* **CSS3:** Diseño personalizado con temática "Aura Dark" y Responsive Design.
* **JavaScript (Vanilla):** Animaciones de entrada e interacción.
* **Formspree:** Gestión de mensajería para el formulario de contacto.

##  Proyectos Incluidos
1. **Venta de Libros Artesanales:** E-commerce enfocado en la estética y encuadernación.
2. **Portfolio Personal:** Esta misma plataforma de presentación.
3. **Landing Pages:** Páginas de aterrizaje optimizadas para conversión.
